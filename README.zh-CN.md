# Rhino 转 SketchUp（3DM → SKP）

这是一个在本机运行的 Python 命令行工具。它将 Rhino 模型导出为原生 SketchUp 几何，保留可转换的组、Block 实例、图层和洞口，并在导出后回读模型，定位可能无法整片推拉的面。

- **输入**：Rhino `.3dm`。不会修改输入文件。
- **输出**：通过检查时生成指定的 `.skp`；未通过时生成高亮诊断文件和报告，不把它标为已验证的导出。
- **运行环境**：目前验证的是 macOS 和 SketchUp 2026 C API。仓库不包含 SketchUp SDK、官方材质或项目模型。安装和命令见 [英文说明](README.md#setup)。
- **边界**：保存后的面结构检查不等于打开界面逐面试推拉。文字、标注、填充以及部分裁剪曲面和极小几何还不能完整转换。

需要按图层上材质时，可重复使用 `--layer-material "图层名=/本机路径/材质.skm"`。未通过检查时，加 `--unmarked-review` 可额外得到不标橙色的复核副本，检查结果和退出码不变。
